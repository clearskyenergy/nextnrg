How this number was arrived at

InputBasisDetail
IrradianceassumedOffline estimate: annual GHI interpolated from published station normals, nearest 6 km away, then split across the months by sun angle. No site-specific weather was reached. Add a free NREL key under Settings › API Keys for a measured answer.
Weather variabilitymodelledDaily clearness sampled from the Hollands-Huget distribution about each month’s mean, seeded from the site coordinates so the same site returns the same year.
Sky modelmodelledHDKR anisotropic transposition with ASHRAE incidence-angle modifier. Ground albedo 0.20.
Ambient temperatureassumedLatitude climatology with an 11 °C diurnal swing. Cell temperature by the Sandia model. This affects the shape more than the total; where PVWatts calibration is applied, the total is corrected.
DC/AC ratio and clippingmodelledDC/AC 1.25:1. Clipping computed hour by hour: 8,451 kWh/yr, 0.4% of gross.
System lossesassumedsoiling 2.0%, mismatch 2.0%, wiring 2.0%, connections 0.5%, lid 1.5%, nameplate 1.0%, availability 3.0%, shading 3.0%. Each is separate and editable — a single blanket figure hides which one is doing the work.
Array 1 orientationmeasuredTilt 22° — array properties. Azimuth 180° — derived from row angle 90°.
Array 2 orientationmeasuredTilt 8° — array properties. Azimuth 180° — derived from row angle 90°.
Load profileassumedShape synthesised from a 1,800 kW peak and a 52% load factor. A synthesised shape cannot tell you when your real peak falls, which is the thing demand shaving turns on. Import interval data before relying on the savings figure.
Demand chargemeasured$16.50/kW-month — imported bill.
Battery dispatchmodelledLowest holdable monthly threshold found by bisection with state of charge tracked hour by hour. Round-trip 88%, depth of discharge 95%. Charging is confined to the headroom below the threshold so it cannot set a new peak.
